使用说明与支持范围

点“导出 PDF”后，在浏览器打印窗口选择“另存为 PDF”，使用 100% 缩放，关闭浏览器页眉和页脚。导出前会等待字体和图片加载。建议使用最新版 Edge 或 Chrome。

支持数学公式、四类嵌套折叠框、表格横纵合并、Tuack / 三线表、左右与居中对齐、引言、代码高亮与行号、任务列表和脚注。视频在纸上以 BV/AV 编号和地址表示。

程序和公式字体均已内置，无须联网。远程图片仍需联网；导入本地图片后可嵌入导出的 HTML。文档不会上传。原始 HTML 按洛谷规则作为文字显示。

语法依据：洛谷 Markdown 格式手册。渲染依赖及许可见随附 THIRD-PARTY-NOTICES.md。
